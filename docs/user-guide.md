# Wasel User Guide — Planned Workflow

1. Connect the Android phone and computer to the same Wi-Fi network, or connect the computer to the phone hotspot.
2. Open Wasel on Android and start receiving.
3. Open the displayed local address in the computer browser.
4. Pair the computer using the displayed QR code or temporary code.
5. Approve the connection on Android.
6. Choose files to send and approve incoming transfers.
7. Wait for integrity verification before considering a transfer complete.

This guide describes the intended workflow. It must be updated as features are implemented.
